# Публичные CRDT-контракты

Файлы `store/crdt-doc/types` определяют независимый от реализации API, которым пользуется модель документа Rivto. Прикладному коду следует работать с этими контрактами, если ему не нужна специфичная возможность Yjs.

## `Serializible`

Базовый интерфейс всех shared-контейнеров.

### `toJSON()`

- **Аргументы:** отсутствуют.
- **Возвращает:** `BasicType`.
- **Исключения:** общий контракт не задаёт; конкретный адаптер может отклонить неприсоединённое или неподдерживаемое значение.

Возвращает текущее значение как `BasicType`: JSON-совместимые примитивы, массивы, обычные объекты и `null`. CRDT-wrapper, метаданные и история Yjs в результат не попадают.

## `CRDTDoc`

Корневой контракт совместного документа. `DocumentModelImpl` принимает этот интерфейс, а `YjsDoc` является стандартной реализацией.

### `id`

- **Тип:** `string`, только для чтения.
- **Значение:** логический идентификатор документа.
- **Исключения при чтении:** контракт не задаёт.

Возвращает логический ID документа, заданный адаптеру. Провайдер может использовать другой ID комнаты, поэтому это не сетевой адрес.

### `instantiator`

- **Тип:** `CRDTInstantiator`, только для чтения.
- **Значение:** фабрика shared-типов текущего адаптера.
- **Исключения при чтении:** контракт не задаёт.

Возвращает `CRDTInstantiator` текущей реализации. Менеджеры создают через него совместимые карты, массивы и текст, не импортируя Yjs.

### `attachProvider(provider)`

- **Аргументы:** `provider: any` в текущем интерфейсе; фактически ожидается совместимый `Provider`.
- **Возвращает:** `Promise<void>`, завершённый после подключения.
- **Исключения:** контракт не задаёт; Promise может быть отклонён провайдером или адаптером.

Подключает провайдер синхронизации. Провайдер транспортирует изменения; без него документ продолжает работать локально.

### `detachProvider()`

- **Аргументы:** отсутствуют.
- **Возвращает:** `Promise<void>` после отключения.
- **Исключения:** контракт не задаёт; реализация может отклонить Promise, если провайдер не подключён или cleanup завершился ошибкой.

Отключает провайдер. Текущая Yjs-реализация удаляет один сохранённый провайдер за вызов, поэтому владелец должен явно контролировать порядок teardown.

### `transact(operation, origin?)`

- **Аргументы:** `operation: () => void`; необязательный `origin: unknown` помечает источник транзакции.
- **Возвращает:** `void`.
- **Исключения:** исключение из `operation` или CRDT-адаптера передаётся вызывающему коду.

Выполняет связанные изменения как одну CRDT-транзакцию. `DocumentModelImpl.transact()` использует метод для всех публичных мутаций и передаёт стабильный локальный origin для undo.

### `createUndoManager(scopes, trackedOrigins?)`

- **Аргументы:** `scopes: CRDTUndoScope[]`; необязательный `trackedOrigins: unknown[]`.
- **Возвращает:** `CRDTUndoManager`.
- **Исключения:** контракт не задаёт; адаптер может отклонить несовместимую или detached-область.

Создаёт undo manager для переданных карт, массивов и текстов. Rivto передаёт собранные области документа и локальный origin, чтобы удалённые updates не считались локальной историей.

`scopes` — это не строки путей и не snapshot-данные. Это массив живых экземпляров `CRDTMap`, `CRDTArray` или `CRDTText`, изменения которых должен отслеживать manager. Обычно передаются корневые контейнеры функциональной области: вложенные shared-типы под таким корнем также относятся к ней. Все scopes должны быть созданы тем же CRDT-адаптером, принадлежать тому же документу и уже быть присоединены к нему.

```ts
const document = new YjsDoc("manual-undo");
const blocks = document.getMap("blocks");
const roots = document.getArray<string>("roots");
const localOrigin = Symbol("local-edit");

const history = document.createUndoManager(
  [blocks, roots], // CRDTUndoScope[]
  [localOrigin],   // транзакции только с этим origin
);

document.transact(() => {
  blocks.set("first", { type: "paragraph" });
  roots.push("first");
}, localOrigin);

history.undo();
history.redo();
history.destroy();
```

Если передан `trackedOrigins`, undo записывает только транзакции с одним из этих origin. Один и тот же объект origin нужно передать и в `createUndoManager`, и в `transact`: новый `Symbol()` при каждом вызове не совпадёт с предыдущим.

При обычной работе через Rivto вручную собирать scopes не нужно. `DocumentModelImpl` объединяет `undoScopes` менеджеров блоков, элементов, связей и plugin data, а публичный `UndoManager` вызывает:

```ts
document.crdt.createUndoManager(document.undoScopes, [document.origin]);
```

Новый manager persisted-состояния должен предоставить свои корневые shared-контейнеры в `undoScopes`, после чего `DocumentModelImpl` добавляет их в общий массив. Не добавляйте один корень несколько раз и не передавайте plain object, snapshot или wrapper из другого документа.

### `getArray(path)`

- **Аргументы:** `path: string`; generic `Item extends CRDTType` задаёт тип элементов.
- **Возвращает:** `CRDTArray<Item>`.
- **Исключения:** контракт не задаёт; адаптер может отклонить путь, уже занятый корнем другого типа.

Возвращает или создаёт присоединённый корневой `CRDTArray`. Менеджер блоков хранит в `roots` упорядоченные ID верхнеуровневых блоков.

### `getMap(path)`

- **Аргументы:** `path: string`; generic `Schema extends object` задаёт ключи и значения.
- **Возвращает:** `CRDTMap<Schema>`.
- **Исключения:** контракт не задаёт; адаптер может отклонить путь, уже занятый корнем другого типа.

Возвращает или создаёт корневой `CRDTMap`. Менеджеры используют корни `blocks`, `elements`, `links` и `plugins`.

### `getText(path)`

- **Аргументы:** `path: string`.
- **Возвращает:** `CRDTText`.
- **Исключения:** контракт не задаёт; адаптер может отклонить путь, уже занятый корнем другого типа.

Возвращает или создаёт корневой `CRDTText`. В Rivto текст обычно вложен в карту блока, а не хранится отдельным корнем.

### `on(event, handler)`

- **Аргументы:** `event: "update" | "sync" | "snapshot"`; `handler: (event: any) => void`.
- **Возвращает:** `Unsubscribe`, функцию без аргументов с результатом `void`.
- **Исключения:** контракт не задаёт; исключения самого handler возникают во время доставки события.

Подписывается на событие и возвращает `Unsubscribe`. Общий контракт называет `update`, `sync` и `snapshot`; текущий `YjsDoc` напрямую передаёт нативному документу `update` и `sync`. Сам проект использует `update` для уведомления подписчиков.

Контракт объявляет **три допустимых имени событий**, но один вызов `on()` подписывает handler только на одно выбранное имя:

- `update` — изменение CRDT document; включает local и применённые remote updates;
- `sync` — adapter/provider-specific состояние синхронизации;
- `snapshot` — adapter-specific notification о snapshot lifecycle.

Число одновременных handlers контрактом не ограничено. Повторный `on()` не должен заменять ранее зарегистрированный другой handler: каждый вызов возвращает cleanup своей подписки. Контракт не фиксирует deduplication одной и той же function reference — это деталь adapter-а — поэтому portable consumer должен создавать одну подписку и хранить её `Unsubscribe`, если ему нужен ровно один callback.

`on()` не обязан немедленно вызывать handler текущим состоянием. Это event stream, а не `getSnapshot()`: initial state нужно прочитать отдельно. После `unsubscribe()` handler не должен получать будущие события этой подписки; cleanup следует вызывать при teardown.

**Built-in ограничение:** текущий `YjsDoc` фактически реализует сигнатуру `on("update" | "sync", ...)`, а `snapshot` отсутствует в implementation signature и не emitted методом `getSnapshot()`. Кроме того, `Y.Doc` сам не публикует provider sync status. Для встроенного adapter-а надёжно поддерживаемым document event является `update`; sync lifecycle нужно слушать через конкретный provider.

### `getSnapshot()`

- **Аргументы:** отсутствуют.
- **Возвращает:** implementation-specific значение (`any` в текущем контракте).
- **Исключения:** контракт не задаёт.

Возвращает бинарный snapshot конкретной реализации. В `YjsDoc` это Yjs state update.

### `applySnapshot(snapshot)`

- **Аргументы:** `snapshot: any`, совместимый с текущим адаптером.
- **Возвращает:** `void`.
- **Исключения:** адаптер может отклонить повреждённый или несовместимый snapshot.

Объединяет бинарный snapshot с документом. Для Yjs повторное применение update безопасно и приводит реплики к одному состоянию.

### `toJSON()`

- **Аргументы:** отсутствуют.
- **Возвращает:** `BasicType`.
- **Исключения:** реализация может отклонить неразрешённый или несериализуемый корень.

Преобразует разрешённые корни в обычные данные. Это API диагностики и общего преобразования, а не версионированный snapshot редактора.

### `destroy()`

- **Аргументы:** отсутствуют.
- **Возвращает:** `Promise<void>` после отключения providers и уничтожения внутренних ресурсов.
- **Исключения:** ошибки provider disconnect или adapter cleanup.

Освобождает providers, ресурсы и listeners документа. `EditorRuntime.destroy()` вызывает и ожидает этот метод автоматически.

## `CRDTArray<T>`

Совместная упорядоченная последовательность. Rivto использует массивы для порядка корневых блоков и ID дочерних блоков.

### `get(index)`

- **Аргументы:** `index: number`, индекс с нуля.
- **Возвращает:** `Item | undefined`.
- **Исключения:** контракт не задаёт; адаптер может требовать присоединённый массив.

Возвращает значение по индексу и при необходимости оборачивает вложенный shared-тип.

### `insert(index, ...items)`

- **Аргументы:** `index: number`; rest-параметр `items: Item[]`.
- **Возвращает:** `void`.
- **Исключения:** адаптер может отклонить индекс или несовместимое значение.

Вставляет значения перед `index`. CRDT-wrapper преобразуются в нативное представление адаптера.

### `push(...items)`

- **Аргументы:** rest-параметр `items: Item[]`.
- **Возвращает:** `void`.
- **Исключения:** адаптер может отклонить несовместимое значение.

Добавляет значения в конец. Изменение shared-массива позволяет объединить конкурирующие операции порядка.

### `delete(index, count = 1)`

- **Аргументы:** `index: number`; необязательный `count: number`, по умолчанию `1`.
- **Возвращает:** `void`.
- **Исключения:** контракт не задаёт; адаптер может отклонить некорректный диапазон.

Удаляет `count` элементов начиная с `index`.

### `length`

- **Тип:** `number`, только для чтения.
- **Значение:** количество элементов.
- **Исключения при чтении:** адаптер может требовать присоединённый массив.

Возвращает текущее количество элементов.

### `forEach(callback)`

- **Аргументы:** `callback: (value: Item, index?: number, array?: CRDTArray<Item>) => void`.
- **Возвращает:** `void`.
- **Исключения:** ошибки чтения адаптера и исключения callback передаются вызывающему коду.

Последовательно вызывает callback со значением, индексом и текущим wrapper массива.

### `toArray()`

- **Аргументы:** отсутствуют.
- **Возвращает:** `BasicType[]`.
- **Исключения:** адаптер может требовать присоединение или отклонить неподдерживаемое вложенное значение.

Рекурсивно преобразует shared-последовательность в отсоединённый JS-массив значений `BasicType`.

### `toJSON()`

- **Аргументы:** отсутствуют.
- **Возвращает:** `BasicType`, фактически массив для `CRDTArray`.
- **Исключения:** те же, что у `toArray()`.

Возвращает рекурсивно преобразованный JSON-совместимый массив.

## `CRDTMap<T>`

Совместный контейнер со строковыми ключами. Это основной примитив для записей и реестров модели документа.

### `observe(callback)`

- **Аргументы:** `callback: (events: unknown, transaction: unknown) => void`.
- **Возвращает:** `() => void` для удаления observer.
- **Исключения:** контракт не задаёт; исключения callback возникают при доставке события.

Подписывается на глубокие изменения внутри карты и возвращает функцию отписки. Используйте для сигнала конкретного поддерева; модель обычно слушает общий `update` документа.

### `get(key)`

- **Аргументы:** `key: Key extends keyof Schema & string`.
- **Возвращает:** `Schema[Key] | undefined`.
- **Исключения:** адаптер может требовать присоединённую карту или отклонить вложенное значение.

Возвращает значение ключа, оборачивая нативные shared-типы в CRDT-контракты.

### `set(key, value)`

- **Аргументы:** `key: Key`; `value: Schema[Key] & CRDTType`.
- **Возвращает:** текущую карту (`this`).
- **Исключения:** адаптер может отклонить несовместимое значение или недопустимую интеграцию shared-типа.

Сохраняет примитив, обычное значение или совместимый wrapper и возвращает текущую карту. Вложенный CRDT-контейнер редактируется независимо; обычный объект остаётся атомарным, если его заранее не преобразовали.

### `length` и `size`

- **Тип:** оба `number`, только для чтения.
- **Значение:** количество пар ключ-значение.
- **Исключения при чтении:** адаптер может требовать присоединённую карту.

Оба свойства возвращают число ключей. `size` соответствует JS `Map`, а `length` сохранён в общем CRDT-контракте.

### `keys()`

- **Аргументы:** отсутствуют.
- **Возвращает:** `MapIterator<keyof Schema & string>`.
- **Исключения:** адаптер может требовать присоединённую карту.

Возвращает iterator строковых ключей.

### `values()`

- **Аргументы:** отсутствуют.
- **Возвращает:** `MapIterator<Schema[keyof Schema]>`.
- **Исключения:** возможны ошибка detached-состояния или ошибка преобразования вложенного значения.

Возвращает iterator значений с обёрнутыми shared-типами.

### `entries()`

- **Аргументы:** отсутствуют.
- **Возвращает:** `MapIterator<[keyof Schema & string, Schema[keyof Schema]]>`.
- **Исключения:** возможны ошибка detached-состояния или ошибка преобразования вложенного значения.

Возвращает iterator пар `[key, value]` с обёрнутыми значениями.

### `has(key)`

- **Аргументы:** `key: keyof Schema & string`.
- **Возвращает:** `boolean`.
- **Исключения:** адаптер может требовать присоединённую карту.

Проверяет наличие ключа.

### `delete(key)`

- **Аргументы:** `key: keyof Schema & string`.
- **Возвращает:** `void`.
- **Исключения:** контракт не задаёт.

Удаляет ключ. Метод возвращает `void`; если важен факт существования, сначала вызовите `has(key)`.

### `clear()`

- **Аргументы:** отсутствуют.
- **Возвращает:** `void`.
- **Исключения:** контракт не задаёт.

Удаляет все записи. Загрузка snapshot использует clear-and-assign внутри транзакции.

### `forEach(callback)`

- **Аргументы:** `callback: (value, key, map?) => void` с типами из `Schema`.
- **Возвращает:** `void`.
- **Исключения:** ошибки чтения/преобразования и исключения callback передаются вызывающему коду.

Передаёт callback обёрнутое значение, ключ и текущую карту.

### `toObject()`

- **Аргументы:** отсутствуют.
- **Возвращает:** `Record<string, BasicType>`.
- **Исключения:** возможны ошибка detached-состояния или неподдерживаемое вложенное значение.

Рекурсивно преобразует карту в отсоединённый обычный объект из `BasicType`.

### `toMap()`

- **Аргументы:** отсутствуют.
- **Возвращает:** `Map<string, BasicType>`.
- **Исключения:** возможны ошибка detached-состояния или неподдерживаемое вложенное значение.

Рекурсивно преобразует карту в отсоединённый JS `Map`.

### `toJSON()`

- **Аргументы:** отсутствуют.
- **Возвращает:** `BasicType`, фактически обычный объект для `CRDTMap`.
- **Исключения:** те же, что у `toObject()`.

Возвращает рекурсивно преобразованный JSON-совместимый объект.

## `CRDTText`

Совместный rich text. Содержимое блока использует этот контракт, чтобы параллельные правки символов и форматирования могли объединяться.

### `insert(position, text, attributes?)`

- **Аргументы:** `position: number`; `text: string`; необязательный `attributes: Record<string, unknown>`.
- **Возвращает:** `void`.
- **Исключения:** контракт не задаёт; адаптер может отклонить позицию или атрибуты.

Вставляет текст по символьному смещению с необязательными атрибутами форматирования.

### `delete(position, length)`

- **Аргументы:** `position: number`; `length: number`.
- **Возвращает:** `void`.
- **Исключения:** контракт не задаёт; адаптер может отклонить диапазон.

Удаляет диапазон символов.

### `format(position, length, attributes)`

- **Аргументы:** `position: number`; `length: number`; `attributes: Record<string, unknown>`.
- **Возвращает:** `void`.
- **Исключения:** контракт не задаёт; адаптер может отклонить диапазон или атрибуты.

Применяет или снимает форматирование диапазона.

### `toDelta()`

- **Аргументы:** отсутствуют.
- **Возвращает:** `CRDTTextDelta[]`.
- **Исключения:** адаптер может требовать присоединённый текст.

Возвращает упорядоченные операции вставки текста и их атрибуты. Текущий Yjs-wrapper пропускает встроенные нетекстовые объекты.

### `length`

- **Тип:** `number`, только для чтения.
- **Значение:** длина текста в единицах текущего адаптера.
- **Исключения при чтении:** адаптер может требовать присоединённый текст.

Возвращает длину текста в UTF-16, что соответствует смещениям Yjs и JavaScript.

### `toString()`

- **Аргументы:** отсутствуют.
- **Возвращает:** `string`.
- **Исключения:** адаптер может требовать присоединённый текст.

Возвращает обычный текст без форматирования.

### `toJSON()`

- **Аргументы:** отсутствуют.
- **Возвращает:** `BasicType`, фактически `string` для `CRDTText`.
- **Исключения:** те же, что у `toString()`.

Возвращает ту же строку для JSON-сериализации.

## `Provider`

Провайдер подключает `CRDTDoc` к транспорту.

### `id`

- **Тип:** `string`, только для чтения.
- **Значение:** стабильный ключ экземпляра провайдера.
- **Исключения при чтении:** контракт не задаёт.

Стабильный ключ провайдера внутри документа. Встроенные значения: `broadcast` и `webrtc`.

### `connect(document)`

- **Аргументы:** `document: CRDTDoc`.
- **Возвращает:** `Promise<void>` после запуска подключения.
- **Исключения:** Promise может быть отклонён для несовместимого документа, повторного подключения или ошибки транспорта.

Запускает синхронизацию совместимого документа. Встроенные провайдеры отклоняют не-`YjsDoc`, потому что транспортируют нативные Yjs updates.

### `disconnect(document)`

- **Аргументы:** `document: CRDTDoc`.
- **Возвращает:** `Promise<void>` после cleanup.
- **Исключения:** Promise может быть отклонён для несовместимого документа, отсутствующего подключения или ошибки транспорта.

Останавливает синхронизацию и освобождает listeners и ресурсы транспорта.

## `CRDTInstantiator`

Фабрика shared-типов, привязанная к реализации CRDT.

### `createArray()`

- **Аргументы:** отсутствуют; generic `Item` ограничивает элементы.
- **Возвращает:** detached-`CRDTArray<Item>`.
- **Исключения:** контракт не задаёт.

Создаёт пустой неприсоединённый shared-массив.

### `createMap()`

- **Аргументы:** отсутствуют; generic `Schema` описывает ключи и значения.
- **Возвращает:** detached-`CRDTMap<Schema>`.
- **Исключения:** контракт не задаёт.

Создаёт пустую неприсоединённую shared-карту.

### `createText()`

- **Аргументы:** отсутствуют.
- **Возвращает:** detached-`CRDTText`.
- **Исключения:** контракт не задаёт.

Создаёт пустой неприсоединённый shared-текст.

### `convertBasicToCRDTType(item, options?)`

- **Аргументы:** `item: BasicType`; необязательный `options: WrapBasicTypeToCRDTOptions`.
- **Возвращает:** `CRDTType`.
- **Исключения:** реализация может отклонить неподдерживаемое или циклическое значение.

Рекурсивно преобразует поддерживаемые данные. По умолчанию строки становятся CRDT-текстом, массивы — CRDT-массивами, а обычные объекты и JS `Map` — CRDT-картами.

### `isPlainRecord(value)`

- **Аргументы:** `value: BasicType`.
- **Возвращает:** `boolean`.
- **Исключения:** контракт не задаёт.

Проверяет, является ли значение глубоко поддерживаемым ациклическим обычным объектом. Экземпляры классов, функции, символы, `undefined` и циклы отклоняются.

## Контракты undo

`CRDTUndoScope` — это `CRDTMap`, `CRDTArray` или `CRDTText`, изменения которого нужно сохранять в истории.

### `CRDTUndoManager.undo()`

- **Аргументы:** отсутствуют.
- **Возвращает:** `void`.
- **Исключения:** контракт не задаёт; адаптер может передать ошибку восстановления состояния.

Применяет предыдущее сохранённое локальное изменение.

### `CRDTUndoManager.redo()`

- **Аргументы:** отсутствуют.
- **Возвращает:** `void`.
- **Исключения:** контракт не задаёт; адаптер может передать ошибку повторного применения.

Повторно применяет последнее отменённое изменение.

### `CRDTUndoManager.clear()`

- **Аргументы:** отсутствуют.
- **Возвращает:** `void`.
- **Исключения:** контракт не задаёт.

Очищает историю undo и redo.

### `CRDTUndoManager.stopCapturing()`

- **Аргументы:** отсутствуют.
- **Возвращает:** `void`.
- **Исключения:** контракт не задаёт.

Закрывает текущую группу, чтобы следующее изменение стало отдельным элементом undo.

### `CRDTUndoManager.destroy()`

- **Аргументы:** отсутствуют.
- **Возвращает:** `void`.
- **Исключения:** контракт не задаёт.

Освобождает listeners и историю менеджера.

## Типы значений и настроек

### `CRDTTextDelta.insert`

- **Тип:** `string`, обязательное свойство.
- **Значение:** вставляемый текст одного delta-run.
- **Исключения при чтении:** отсутствуют.

### `CRDTTextDelta.attributes`

- **Тип:** `Record<string, unknown> | undefined`.
- **Значение:** форматирование соответствующего `insert`; свойство может отсутствовать.
- **Исключения при чтении:** отсутствуют.

### `Unsubscribe`

- **Аргументы функции:** отсутствуют.
- **Возвращает:** `void`.
- **Исключения:** зависят от cleanup конкретной подписки; общий alias их не задаёт.

- `BasicType` — рекурсивный домен JSON-совместимых значений сериализации.
- `CRDTType` дополнительно включает CRDT-wrapper, объекты и массивы для построения CRDT.
- `CRDTTextDelta` описывает вставку текста и атрибуты.
- `Unsubscribe` — функция очистки без аргументов.
- `WrapBasicTypeToCRDTOptions` выбирает, какие обычные контейнеры превращать в совместные. Все флаги wrapping по умолчанию равны `true`; каждое поле подробно описано на странице преобразования.
- `ConvertCRDTTypeToBasicOptions` управляет обратным преобразованием карты.
- `CRDTError` — базовая категория ошибок CRDT, независимая от адаптера.

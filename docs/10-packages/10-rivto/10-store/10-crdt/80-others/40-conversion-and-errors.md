# Создание, преобразование и ошибки

Yjs-адаптер хранит правила преобразования в одном месте. Менеджерам документа не приходится использовать `instanceof Y.Map` или зависеть от нативных конструкторов.

## `YjsInstantiator`

Реализует публичный `CRDTInstantiator` и доступен через `YjsDoc.instantiator`.

### `createArray()`

- **Аргументы:** отсутствуют; generic `Item extends CRDTType` задаётся вызывающим кодом.
- **Возвращает:** `CRDTArray<Item>`, фактически новый detached-`YjsArray<Item>`.
- **Исключения:** собственных проверок нет; возможная ошибка конструктора Yjs передаётся.

Возвращает detached-`YjsArray` поверх нового `Y.Array`.

### `createMap()`

- **Аргументы:** отсутствуют; generic `Schema extends object` задаётся вызывающим кодом.
- **Возвращает:** `CRDTMap<Schema>`, фактически новый detached-`YjsMap<Schema>`.
- **Исключения:** собственных проверок нет; возможная ошибка конструктора Yjs передаётся.

Возвращает detached-`YjsMap` поверх нового `Y.Map`.

### `createText()`

- **Аргументы:** отсутствуют.
- **Возвращает:** `CRDTText`, фактически новый detached-`YjsText`.
- **Исключения:** собственных проверок нет; возможная ошибка конструктора Yjs передаётся.

Возвращает detached-`YjsText` поверх нового `Y.Text`.

### `convertBasicToCRDTType(item, options?)`

- **Аргументы:** `item: BasicType`; необязательный `options: WrapBasicTypeToCRDTOptions`.
- **Возвращает:** `CRDTType`.
- **Исключения:** `YjsConvertError` для неподдерживаемого значения; также передаёт ошибки нативных Yjs-конструкторов.

Делегирует общему преобразователю `wrapBasicTypeToCRDTType`. По умолчанию все уровни совместные: строки становятся `YjsText`, массивы — `YjsArray`, а JS `Map` и обычные объекты — `YjsMap`.

Флаги wrapping можно отключить для атомарных значений. Если wrapping родительского контейнера отключён, вложенные уровни тоже остаются обычными: нативные Yjs-типы нельзя хранить внутри неинтегрированного plain-контейнера.

```ts
const value = document.instantiator.convertBasicToCRDTType(
  { label: "обычная строка", tags: ["one"] },
  { string2crdttext: false },
);
```

### `isPlainRecord(value)`

- **Аргументы:** `value: BasicType`.
- **Возвращает:** `boolean`.
- **Исключения:** обычные объекты не приводят к ошибке; exotic object/Proxy может передать ошибку `Object.getPrototypeOf`, `Object.values` или чтения свойства.

Делегирует `isDeepPlainRecord`. Разрешены ациклические объекты из примитивов, массивов и вложенных plain records. Экземпляры классов, функции, символы, `undefined`, неподдерживаемые объекты и циклы запрещены.

## Преобразование wrapper

Функции из `structures/utils/wrap.ts` образуют узкую границу между публичными wrapper и Yjs.

### `unwrapCRDTtoYJS(item)`

- **Аргументы:** `item: CRDTType`.
- **Возвращает:** `YJSType` — нативный shared-тип, примитив или поддерживаемый plain record.
- **Исключения:** обычный `Error` для `undefined`, raw Yjs-типа или JS `Map`; `YjsConvertError` для другого неподдерживаемого значения.

Оставляет примитивы и `null` без изменений, а `YjsArray`, `YjsMap` и `YjsText` превращает в нативные объекты. Сырые Yjs-типы, JS `Map`, `undefined` и неподдерживаемые объекты отклоняются, чтобы слои нельзя было случайно смешать.

Функцию вызывают `YjsArray.insert`, `YjsArray.push` и `YjsMap.set`.

### `wrapYJStoCRDT(item)`

- **Аргументы:** `item: YJSType`.
- **Возвращает:** `CRDTType` — wrapper, примитив или plain record.
- **Исключения:** обычный `Error` для уже обёрнутого `YjsMap`/`YjsArray`/`YjsText`; `YjsConvertError` для неподдерживаемого значения.

Оборачивает нативные `Y.Array`, `Y.Map` и `Y.Text`. Поддерживаемые basic-значения проходят без изменений. Уже обёрнутый CRDT-объект означает ошибочное направление преобразования и приводит к исключению.

Её используют методы чтения wrapper-классов.

## Рекурсивные преобразования

Публичный wrapper-преобразователь находится в `structures/utils/wrap.ts`, а рекурсивные преобразования нативных Yjs-значений — в `structures/utils/yjs-converters.ts`.

### `wrapBasicTypeToCRDTType(item, options?)`

- **Аргументы:** `item: BasicType`; необязательный `options: WrapBasicTypeToCRDTOptions`.
- **Возвращает:** `CRDTType`.
- **Исключения:** передаёт `YjsConvertError`, ошибки wrapping и ошибки нативных Yjs-конструкторов.

Комбинирует `convertBasicTypeToYJS` и `wrapYJStoCRDT`. Это основная точка входа для `YjsInstantiator` и `YjsDoc.fromJSON()`.

### `convertBasicTypeToYJS(item, options?)`

- **Аргументы:** `item: BasicType`; необязательный `options: WrapBasicTypeToCRDTOptions`.
- **Возвращает:** `YJSType`.
- **Исключения:** `YjsConvertError` для неподдерживаемого `typeof`; ошибки обхода циклических/exotic объектов и нативных Yjs-операций передаются.

Рекурсивно переводит поддерживаемые данные в нативные Yjs-типы согласно `WrappingOptions`. Числа, boolean и `null` остаются атомарными. Строки, массивы, карты и объекты либо оборачиваются, либо сохраняются обычными.

Неподдерживаемое значение приводит к `YjsConvertError`. Функция внутренняя, потому что приложение должно получать wrapper, а не нативный Yjs-тип.

### `convertYJSTypeToBasic(item, options?)`

- **Аргументы:** `item: YJSType`; необязательный `options: ConvertCRDTTypeToBasicOptions`.
- **Возвращает:** `BasicType`.
- **Исключения:** `YjsConvertError` для неподдерживаемого значения; ошибки обхода exotic object/Proxy передаются.

Рекурсивно переводит Yjs и plain-значения в `BasicType`. По умолчанию `Y.Map` становится объектом; с `crdtmap2map: true` результатом будет JS `Map`.

## Проверка plain records

### `isDeepPlainRecord(item)`

- **Аргументы:** `item: unknown`; внутренний необязательный `visited: WeakSet<object>` используется рекурсией.
- **Возвращает:** type predicate `item is Record<string, any>`.
- **Исключения:** для обычных значений не выбрасывает; ошибки traps у `Proxy` или встроенных операций над exotic object передаются.

Рекурсивно проверяет корневой обычный объект. Вложенными значениями могут быть массивы и примитивы, но корень обязан быть record. Множество посещённых объектов обнаруживает циклы.

### `isPrimitive(item)`

- **Аргументы:** `item: unknown`.
- **Возвращает:** `boolean`.
- **Исключения:** отсутствуют.

Внутренний helper распознаёт строку, число, boolean и `null`. `undefined` намеренно не поддерживается.

## Публичные ошибки

### `CRDTError`

- **Тип:** публичный класс, наследующий `Error`.
- **Свойства:** `name === "CRDTError"` после создания; остальные свойства наследуются от `Error`.

Независимый от адаптера базовый класс. Наследует `Error`; конструктор задаёт имя `CRDTError`.

#### `constructor(message)`

- **Аргументы:** `message: string`.
- **Создаёт:** `CRDTError` с `name === "CRDTError"` и переданным `message`.
- **Исключения:** собственных проверок нет.

### `YjsError`

- **Тип:** публичный класс, наследующий `CRDTError`.
- **Свойства:** `name === "YjsError"` после создания; остальные свойства наследуются.

Базовая Yjs-ошибка поверх `CRDTError`. Конструктор передаёт сообщение и задаёт имя `YjsError`.

#### `constructor(message)`

- **Аргументы:** `message: string`.
- **Создаёт:** `YjsError` с `name === "YjsError"`.
- **Исключения:** собственных проверок нет.

### `YjsUndefinedError`

- **Конструктор:** наследует `constructor(message: string)` от `YjsError`.
- **Свойства:** наследует `name`, `message`, `stack` и `cause` от цепочки `YjsError`/`Error`; отдельные поля не объявляет.
- **Исключения конструктора:** собственных проверок нет.

Возникает, если wrapper или преобразование ожидает нативный объект, но получает отсутствующее значение.

### `YjsNotAttachedError`

- **Конструктор:** наследует `constructor(message: string)` от `YjsError`.
- **Свойства:** наследует свойства `Error`; отдельные поля не объявляет.
- **Исключения конструктора:** собственных проверок нет.

Возникает при попытке чтения shared-типа до его интеграции в документ.

## Внутренние ошибки

### `YjsInvalidJSONError`

- **Конструктор:** наследует `constructor(message: string)` от `YjsError`.
- **Свойства:** наследует свойства `Error`; отдельные поля не объявляет.
- **Исключения конструктора:** собственных проверок нет.

Зарезервирован для некорректного JSON-преобразования. Экспортируется Yjs-подмодулем, но не корневым barrel `crdt-doc`. Текущие `YjsDoc.toJSON()` и `fromJSON()` пока выбрасывают обычный `Error`.

### `YjsUtilsError`

- **Тип:** внутренний класс, наследующий `Error`.
- **Свойства:** `name === "YjsUtilsError"` после создания; остальные свойства наследуются.

Базовая внутренняя ошибка wrapping и conversion. Конструктор задаёт отдельное имя для диагностики.

#### `constructor(message)`

- **Аргументы:** `message: string`.
- **Создаёт:** `YjsUtilsError` с `name === "YjsUtilsError"`.
- **Исключения:** собственных проверок нет.

### `YjsConvertError`

- **Тип:** внутренний класс, наследующий `YjsUtilsError`.
- **Свойства:** `name === "YjsConvertError"` после создания; остальные свойства наследуются.

Наследует `YjsUtilsError` и обозначает неподдерживаемые или некорректные данные преобразования.

#### `constructor(message)`

- **Аргументы:** `message: string`.
- **Создаёт:** `YjsConvertError` с `name === "YjsConvertError"`.
- **Исключения:** собственных проверок нет.

## Свойства типов настроек

### `WrapBasicTypeToCRDTOptions.string2crdttext`

- **Тип:** `boolean | undefined`.
- **Значение:** преобразовывать ли строки в `Y.Text`; значение по умолчанию — `true`.
- **Исключения при чтении:** отсутствуют.

### `WrapBasicTypeToCRDTOptions.array2crdtarray`

- **Тип:** `boolean | undefined`.
- **Значение:** преобразовывать ли массивы в `Y.Array`; значение по умолчанию — `true`.
- **Исключения при чтении:** отсутствуют.

### `WrapBasicTypeToCRDTOptions.map2crdtmap`

- **Тип:** `boolean | undefined`.
- **Значение:** преобразовывать ли JS `Map` в `Y.Map`; значение по умолчанию — `true`.
- **Исключения при чтении:** отсутствуют.

### `WrapBasicTypeToCRDTOptions.object2crdtmap`

- **Тип:** `boolean | undefined`.
- **Значение:** преобразовывать ли обычные объекты в `Y.Map`; значение по умолчанию — `true`.
- **Исключения при чтении:** отсутствуют.

### `ConvertCRDTTypeToBasicOptions.crdtmap2map`

- **Тип:** `boolean | undefined`.
- **Значение:** возвращать ли `Y.Map` как JS `Map`; по умолчанию `false`, то есть возвращается обычный объект.
- **Исключения при чтении:** отсутствуют.

## Общие свойства ошибок

- **`name: string`:** имя класса ошибки, выставляемое соответствующим конструктором; чтение не выбрасывает исключений.
- **`message: string`:** переданное диагностическое сообщение; чтение не выбрасывает исключений.
- **`stack?: string`:** стек, формируемый JavaScript runtime; может отсутствовать, чтение не выбрасывает исключений.
- **`cause?: unknown`:** унаследованное поле `Error`; эти конструкторы его явно не заполняют.

## Где обрабатывать ошибки

Обычному приложению не требуется их перехватывать: работу со схемой выполняют менеджеры Rivto. Обрабатывайте CRDT-ошибки на границе адаптера — например, при импорте общих данных или подключении пользовательского провайдера, где приложение может сообщить о несовместимом вводе.

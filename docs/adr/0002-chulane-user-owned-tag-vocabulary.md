# Chulane tags belong to users rather than projects

Tags carry descriptions that explain their meaning to AI agents and must be reusable across projects. Chulane therefore assigns tag definitions to users rather than individual projects, avoiding project inheritance and project-specific reuse restrictions. Pages can contain undefined `#name` labels; hovering resolves a description or offers to define the tag, rather than requiring a tag record before writing. Which user's definition applies on a shared page remains open.
